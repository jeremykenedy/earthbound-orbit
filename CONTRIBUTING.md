# Contributing

Keep changes specific to Earthbound Orbit and follow its existing Java and Python style. Do not add runtime network access, telemetry, analytics, ads, or tracking. Preserve the Apache-2.0 notices and signing identity rules.

Run the checks listed in [testing](docs/TESTING.md) before opening a pull request. Include emulator or physical-device details for changes that affect DreamService behavior. Never claim a platform or hardware behavior without testing it on that platform.
