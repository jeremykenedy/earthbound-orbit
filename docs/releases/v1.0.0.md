# Earthbound Orbit 1.0.0

First stable release of the animated Earthbound Orbit screensaver.

## Changes

- Added a continuously rotating Earth sphere with NASA Blue Marble imagery, day and night shading, and an optional atmospheric rim.
- Added independent controls for star density, Earth rotation, atmosphere glow, and camera movement, with per-setting and global randomization.
- Added a remote-friendly settings activity, full-screen preview, validated settings provider, and standalone installer.
- Added a signed APK and SHA-256 checksum.

## Compatibility and verification

Requires Android 6.0 (API 23) or later and OpenGL ES 2.0. Device verification is recorded in the [verification matrix](../VERIFICATION.md). Physical Fire TV, Android TV, and Google TV devices have not been tested.

## Installation and upgrade

Install with `python3 install.py --serial TV_IP:5555` or follow the [installation guide](../INSTALLATION.md). Future in-place updates require the same package ID and release signing certificate. This initial release has no prior version to upgrade from and introduces no breaking changes.
